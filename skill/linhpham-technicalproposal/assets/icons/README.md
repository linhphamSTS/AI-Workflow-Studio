# Icon packs

Eight packs bundled. SVG sources are committed; PNG renders are produced at deploy time
(see `tools/prerender_icons.py`) and excluded from git.

| Pack | Source | License |
|---|---|---|
| `aws/` | AWS Architecture Icons (official) | Trademark of Amazon Web Services |
| `azure/` | Azure architecture icons (official) | Trademark of Microsoft |
| `gcp/` | Google Cloud architecture icons (official) | Trademark of Google |
| `generic/` | Self-drawn neutral shapes (server, db, cloud, network) | CC0 |
| `container/` | CNCF Landscape (Docker, Kubernetes, Helm, containerd) | per upstream (mostly Apache-2 / CC) |
| `network/` | Cisco icons + self-drawn shapes (firewall, LB, VPN, switch, CDN, WAF) | per upstream |
| `data/` | Simple Icons + Devicon (Kafka, Spark, Airflow, dbt, Snowflake, Databricks, Flink, NiFi) | CC0 / MIT |
| `ai/` | lobehub/lobe-icons + self-drawn (LLMs, vector DBs, LangChain, MCP) | MIT |

Pre-rendered at **200 DPI and 300 DPI** for sharp embedding in Word at 6.5 in width.
